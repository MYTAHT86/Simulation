2 проект роадмапа симуляция на Python в ООП стиле, реалиазация консольная 

Требования для запуска

Python 3.10 или новее.
Операционная система Windows.
Внешняя библиотека wcwidth.

Установка зависимости:

python -m pip install wcwidth

Запуск симуляции:

Из корневой директории проекта выполнить:
python main.py

Реализацией является карта 16x16. Поиск точки назначения осуществляется через BFS. Добавил механику голода для класса Predator, чтобы взаимодействие со здоровьем было не только у класса Herbivore. Симуляцию можно остановить на англ. клавишу "p", возобновить на англ. клавишу "c" и полностью закончить на англ. клавишу "e"
